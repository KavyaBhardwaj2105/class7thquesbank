This chapter focuses on statistical questions and statements, data collection, representative values, mean, median, outliers, dot plots, variability and data visualisation.

Section A — Multiple Choice Questions (15)

1. Which of the following is a statistical question?

Correct Answer: What are the heights of students in Class 7?

2. Find the mean of 6, 8, 10, 12 and 14.

Correct Answer: 10

3. Find the median of 4, 9, 7, 12, 6.

Arrange: 4, 6, 7, 9, 12. Median = 7.

4. Which value is most likely to be strongly affected by an extremely large outlier?

Correct Answer: Mean

5. The data 3, 5, 5, 6, 8 contains which repeated value?

Correct Answer: 5

6. If the mean of 8 observations is 12, what is their total?

Correct Answer: 96

7. Which is the median of 11, 4, 9, 6, 15, 8, 3?

Ordered data: 3, 4, 6, 8, 9, 11, 15. Median = 8.

8. What is the mean of 5, 5, 5 and 9?

Correct Answer: 6

9. In a dot plot, several dots above the same number indicate:

Correct Answer: Repeated occurrences of that value.

10. Which data set has the greatest variability?

Correct Answer: 2, 10, 18, 26, 34.

11. The data 7, 8, 8, 9, 10 has mean:

Mean = (7+8+8+9+10)/5 = 42/5 = 8.4.

12. Which value is the median of 2, 4, 6, 8, 10, 12?

For six values, median = average of 3rd and 4th: (6+8)/2 = 7.

13. A data set has values 4, 5, 5, 6, 40. Which measure better represents a typical observation?

Correct Answer: Median. The value 40 is an extreme outlier.

14. If every observation in a data set increases by 3, the mean:

Correct Answer: Increases by 3.

15. Which graph is especially useful for displaying how frequently individual values occur?

Correct Answer: Dot plot

Section G — HOTS / Higher Order Thinking (10)

46. Five students scored 12, 15, 18, 20 and 25 marks. What is their average score?

Mean = (12+15+18+20+25)/5 = 90/5 = 18.

47. The mean of four numbers is 15. Three of the numbers are 10, 14 and 18. What is the fourth number?

Total required = 4×15 = 60. Known total = 10+14+18 = 42. Fourth number = 60−42 = 18.

48. The scores of a player are 18, 20, 19, 21 and 70. Which measure gives a more representative idea of the usual score?

Correct Answer: Median. 70 is an extreme value compared with the other scores.

49. Two classes have the following test-score averages: Class A = 18, Class B = 18. Can we conclude that their students performed identically?

Correct Answer: No. Different data sets can have the same mean.

50. A data set is 4, 6, 8, 10, 12. If 20 is added to the set, what happens to the mean?

Original mean = 8. New mean = (4+6+8+10+12+20)/6 = 60/6 = 10. So the mean increases.

51. A teacher records the number of books read by students: 2, 3, 3, 4, 4, 4, 5, 5. What is the median?

There are 8 observations. Middle values are 4 and 4. Median = (4+4)/2 = 4.

52. Data set A is 10, 10, 10, 10, 10. Data set B is 2, 6, 10, 14, 18. Both have mean 10. Which statement is correct?

Correct Answer: B has greater variability because its observations are spread out.

53. A dot plot shows 2 dots at 3, 5 dots at 4 and 3 dots at 5. How many observations are there altogether?

Total observations = 2 + 5 + 3 = 10.

54. A data set has mean 12. If every value is reduced by 5, what will the new mean be?

New mean = 12 − 5 = 7.

55. A school records the travel time of students to school: 15, 16, 15, 17, 16, 15, 60 minutes. What is the best reason for examining the median as well as the mean?

Correct Answer: The 60-minute value may be an outlier and can pull the mean upward.
