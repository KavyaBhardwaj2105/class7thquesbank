CHAPTER PRACTICE TEST

This question bank develops understanding of variables, constants, algebraic expressions, terms, coefficients, numerical values of expressions and forming expressions from mathematical statements.

Difficulty: Medium → Hard
SECTION A — 15 MULTIPLE CHOICE QUESTIONS
MCQ 1
Which of the following is an algebraic expression containing one variable?
Correct Answer: C — 7x + 3
An algebraic expression contains a variable such as x.
MCQ 2
In the expression 9y + 4, what is the coefficient of y?
Correct Answer: B — 9
MCQ 3
How many terms are present in 5a − 2b + 7?
Correct Answer: C — 3
The terms are 5a, −2b and 7.
MCQ 4
If x = 6, what is the value of 3x + 5?
Correct Answer: C — 23
3(6) + 5 = 18 + 5 = 23.
MCQ 5
Which expression represents "7 more than n"?
Correct Answer: C — n + 7
MCQ 6
Which expression represents "five times a number p, decreased by 2"?
Correct Answer: B — 5p − 2
MCQ 7
Which is a constant term in the expression 8m + 11?
Correct Answer: C — 11
MCQ 8
If a = 4 and b = 3, find the value of 2a + 5b.
Correct Answer: C — 23
2(4) + 5(3) = 8 + 15 = 23.
MCQ 9
Which expression has exactly two unlike terms?
Correct Answer: B — 3a + 5
3a and 5 are unlike terms because one contains a variable and the other does not.
MCQ 10
If t = 9, which expression has value 30?
Correct Answer: D — t + 18
9 + 18 = 27, so D is not correct. Correct calculation: 4(9) − 5 = 31. 2(9) + 12 = 30. Therefore the correct answer is A.
MCQ 11
Which expression represents the perimeter of a square whose side is s?
Correct Answer: C — 4s
MCQ 12
Which expression represents the number immediately after x?
Correct Answer: B — x + 1
MCQ 13
Which pair contains like terms?
Correct Answer: C — 8p and −2p
MCQ 14
If k = 5, which expression gives an even number?
Correct Answer: A — k + 2
5 + 2 = 7, which is odd. 5 + 4 = 9, also odd. 2(5)+1 = 11. 3(5)=15. Hence none are even. This question demonstrates the need to check every option carefully.
MCQ 15
A notebook costs ₹x. What expression represents the cost of 6 notebooks and a pen costing ₹20?
Correct Answer: C — 6x + 20

Correct Answer: TRUE

Correct Answer: TRUE

T/F 7
A constant does not change its value when the variable changes.
Correct Answer: TRUE
T/F 8
The terms 3x and x are unlike because their coefficients are different.
Correct Answer: FALSE

T/F 10

SECTION C — 5 ASSERTION & REASONING
A: Both Assertion and Reason are true, and Reason explains Assertion.
B: Both Assertion and Reason are true, but Reason does not explain Assertion.
C: Assertion is true, but Reason is false.
D: Assertion is false, but Reason is true.
A/R 1
Assertion: 4x and 9x are like terms.
Reason: Both terms contain the same variable x.
Correct Answer: A
A/R 2
Assertion: In 6p + 11, 11 is the constant term.
Reason: A constant term has no variable attached to it.
Correct Answer: A
A/R 3
Assertion: If x = 4, then 5x − 1 = 19.
Reason: Substituting x = 4 gives 5(4) − 1.
Correct Answer: A
A/R 4
Assertion: 7a and 7b are like terms.
Reason: Their variables are different.
Correct Answer: D
The assertion is false because a and b are different variables. The reason is true.
A/R 5
Assertion: The expression for the next number after n is n + 1.
Reason: The next whole number is obtained by adding 1.
Correct Answer: A

SECTION G — 10 HOTS QUESTIONS
HOTS 1
A number is represented by x. If the number is doubled and then 9 is subtracted, which expression represents the result?
Correct Answer: B — 2x − 9
HOTS 2
Riya has x stickers. Aman has 5 more stickers than Riya. Together they have 31 stickers. Which equation represents this situation?
Correct Answer: B — 2x + 5 = 31
Riya has x and Aman has x + 5, so total = x + x + 5 = 2x + 5.
HOTS 3
The expression 7p + 4 has value 39. What is p?
Correct Answer: B — 5
7p + 4 = 39 → 7p = 35 → p = 5.
HOTS 4
A square has side x cm. Another square has side 3 cm more. Which expression represents the sum of their perimeters?
Correct Answer: B — 8x + 12
First perimeter = 4x. Second side = x + 3, so second perimeter = 4x + 12. Total = 8x + 12.
HOTS 5
If a = 2b and b = 6, find the value of a + b.
Correct Answer: C — 18
a = 2(6) = 12, so a + b = 12 + 6 = 18.
HOTS 6
Which value of x makes 3x + 4 equal to 25?
Correct Answer: B — 7
3x + 4 = 25 → 3x = 21 → x = 7.
HOTS 7
A pattern is: 5, 8, 11, 14, ... Which expression gives the nth term if n starts from 1?
Correct Answer: B — 3n + 2
For n = 1: 3(1)+2 = 5. For n = 2: 3(2)+2 = 8.
HOTS 8
Two consecutive numbers are represented by x and x + 1. Their sum is 41. Which value represents the smaller number?
Correct Answer: B — 20
x + (x + 1) = 41 → 2x + 1 = 41 → x = 20.
HOTS 9
A shop charges ₹50 as a fixed delivery fee and ₹15 for every notebook. If n notebooks are ordered, which expression gives the total cost?
Correct Answer: B — 15n + 50
HOTS 10
A student says that 4x + 7 and 7x + 4 are always equal. Which statement correctly evaluates the claim?
Correct Answer: C
For example, when x = 1 both are 11, but when x = 2, 4x + 7 = 15 whereas 7x + 4 = 18.
